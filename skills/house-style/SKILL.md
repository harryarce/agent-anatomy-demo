# House Style Skill

Purpose: Keep customer escalation responses concise, evidence-based, and citation-first.

Rules:
- Always cite one policy clause before recommending action.
- Never mention unrelated customers.
- End with a one-line operational next step.

Example:
Prompt: "Contoso asks for refund on order 4471."
Output style: "Clause 4.2 allows refund review for >7 day delay. Next: verify carrier attribution then issue draft approval."
